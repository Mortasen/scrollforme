Submitting

Through the form on slide 16 of this deck, at claude.echofold.ai.
- **A GitHub repo or a website** One link per team: the repo, or a live site we can open.
- **Make the repo public** So the judging agent can read it. You can make it private again once judging’s done.
- **It’s yours** We don’t do anything with your code and we don’t take anything. You own what you build.
