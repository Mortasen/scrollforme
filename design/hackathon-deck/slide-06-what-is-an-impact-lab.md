The format

A Claude Community hackathon that takes on real problems, here in Dublin
- Problems we named The briefs are the problems the room raised in September, the ones concrete enough to build against.
- One brief, one night Each team picks one and takes a real swing at it. Better one solved than ten started.
- Built to be used It has to run live at the demo, and someone should be able to pick it up and use it after tonight.
